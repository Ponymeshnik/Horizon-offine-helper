# История изменений

## 1.0.0 — 2026-11-08

- Первый выпуск помощника для Minecraft 26.3 и Horizon на Windows.
- Поиск оригинального клиента по содержимому из папки лаунчера, экземпляра или версии.
- Подготовка официальных библиотек и ресурсов, поиск JDK 25 и запуск Horizon.
- Ярлык для повторного запуска, отмена и журнал подготовки.
- 13 встроенных проверок; отдельно проверены реальная подготовка и запуск главного меню.
- Лицензия MIT, исходники и автоматическая сборка для GitHub.

# Changelog

## 1.1.0 — 2026-11-08

- English is now the default interface language, with Russian also available.
- Added a first-launch language picker and a language switch in the main window.
- Saved the language preference separately from the prepared game configuration.
- Localized preparation progress, validation, and helper error messages.
- Added language preference and translation checks, bringing the built-in total to 19.
- Updated both READMEs and included English and Russian usage instructions.

## 1.0.0 — 2026-11-08

- Initial Windows release for Minecraft 26.3 and Horizon.
- Original client discovery from launcher, instance, or version folders.
- Official resource preparation, JDK 25 discovery, and Horizon startup.
- Desktop shortcut, cancellation, and preparation log.
- 13 built-in checks, with real preparation and main-menu startup verified separately.
- MIT license, source code, and a GitHub build workflow.
